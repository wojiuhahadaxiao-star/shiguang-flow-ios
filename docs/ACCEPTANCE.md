# iPhone 实机验收

这些是需要在真实 iPhone / Xcode 环境执行的验收项，并非已通过记录。先用可恢复的测试照片验证删除流程。

## 构建与独立安装
- CI 的 10 个核心模型测试、模拟器编译、设备编译均通过。
- 新旧 App 图标共存；新 App 名称“拾光 Flow”，设置版本为 1.0.0、构建号与下载产物一致。
- 初装：权限按钮确实弹出系统请求；拒绝后按钮转至系统设置；有限权限可追加照片。
- 无照片、只有 1 张、全部标记、未授权都没有崩溃，有明确可操作入口。

## Cover Flow / 性能
- 横图、竖图、全景、截图均保留比例、不裁切，中心卡片视觉大小相近。
- 快速连续左右滑动，照片不串图、不闪回上一张；最终吸附到一张。
- 60 Hz 与支持 120 Hz 的 iPhone 分别检查。使用 Instruments 的 Animation Hitches / Time Profiler 观察掉帧；这里没有给出未经测量的 FPS 保证。
- 上万张相册首次加载 UI 可响应；加载期间显示等待状态。
- 飞行模式 / 仅云端照片有清楚的加载或失败提示，没有空白且不可退出的页面。
- 开启“减弱动态效果”后，Cover Flow 不执行 3D 旋转，转场缩短。

## 删除与撤回
- 慢速上滑不足阈值后松手，照片回弹；超过阈值或快速甩动则标记。
- 主照片上移渐隐、右侧补位；最后一张用左侧补位。
- 连续标记后逐次撤回，原模式、原位置和随机顺序恢复。
- 标记后切换日期模式再撤回，正确回到标记时的位置。
- 杀掉 App 再进入，待删列表仍存在并能撤回。
- 垃圾桶可回看大图；左滑某行撤回、全部撤回均正确。
- 第一次确认取消、第二次确认取消、系统删除取消：系统照片未删，待删列表保留。
- 系统成功删除：只删除确认时捕获的资源 ID，列表清除相应项，系统相册最近删除中可查到。

## 日期 / 分页
- 拍摄日期显示准确；随机选中某张，点击日期进入它在当天时间序列中的组，仍选中它。
- 当日 1、24、25、26、50、51、61 张分别验收。
- 每组不超过 25 张；第一页不能拉出上一组，最后一页不能拉出下一组。
- 边界拉过阈值后松手，只切换一次，出现弹簧过渡；反方向能回上一组。
- 未标记时全部分组拼接后，每张恰好出现一次，时间升序。
- 最后一页最后一张被标记后正确回退，撤回后重新出现。
- 再点日期返回原随机组，原焦点若被标记则落到剩余照片。

## 全屏
- 主界面双击有卡片放大过渡；双指展开可进入全屏。
- 全屏双指缩放、双击局部放大、缩放后的拖动正常。
- 捏回适屏后下滑有跟手淡出和回到原卡片的动画；轻拖取消会回弹。
- 缩放状态下单指拖动用于查看照片，不误触删除或退出。
- 退出后同一张仍在原槽位；iCloud 高清加载过程中也可退出。
- 待删列表的照片可全屏回看，退出仍在列表中。

## P3 新增实机验收
- 连续上滑：照片只垂直向上渐隐，不缩小、不横移；右侧原卡片连续补位，无整体白闪。分别验证随机 / 当日、首项 / 中间 / 末项、仅剩 1 张、当日末页回退。
- 待删从 98 到 99 出现提示；取消保留全部标记；查看进入列表，不自动删除系统照片。
- Live 开关打开时只播放主照片，左右滚动停止旧照片、停稳播放新照片；关闭显示静态图。
- 随机 / 当日 / 全屏 / 待删回看均验证 Live；静音与有声切换立即生效，重启仍保留选择。
- iCloud Live 加载、失败返回静态图、迅速切换照片、后台暂停均无串图或残留声音。
- 全屏放大停止 Live，捏回适屏恢复；下滑返回无残留播放。
